# Project Statement

## Problem Statement
Restaurant billing involves several connected operations: selecting menu items, recording quantities, calculating totals, applying discounts and taxes, handling cancellations, and producing a final bill. When these steps are handled manually, calculation and record-keeping errors can occur.

Dining Behind Doors proposes a modular Python-based solution that models the restaurant order-to-bill workflow and demonstrates how programming concepts can be applied to a practical billing problem.

## Scope
The project covers menu display, order creation and modification, order cancellation, bill calculation, and basic reporting. Payment processing and real payment gateways are outside the current scope.

## Target Users
- Restaurant billing/counter staff
- Small restaurant operators
- Students learning how Python programming concepts can solve a real-world problem

## High-Level Features
1. Menu management
2. Order management
3. Billing and tax/discount calculation
4. Order cancellation
5. Basic sales reporting
6. Input validation
